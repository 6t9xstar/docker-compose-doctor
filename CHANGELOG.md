# Changelog

All notable changes to this project are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-31

### Added

- First release of ComposeDoctor: diagnose Docker Compose files before docker compose up fails.
- Output formats: text, JSON, SARIF 2.1.0, Markdown and GitHub Actions annotations.
- Reusable GitHub Action (`uses: 6t9xstar/docker-compose-doctor@v1`).
